Етап 1. Створення базового класу

Було створено абстрактний клас Message, який містить:

метод send();
метод clone();
поле text.
class Message {
public:
    virtual Message* clone() const = 0;
    virtual void send() const = 0;
};
Етап 2. Створення конкретних прототипів

Було реалізовано три типи повідомлень:

EmailMessage;
SmsMessage;
PushMessage.

Кожен клас реалізує метод clone(), який повертає копію поточного об'єкта.

Етап 3. Реєстр прототипів

Для зберігання готових шаблонів було створено клас MessageRegistry.

У реєстрі зберігаються початкові об'єкти-прототипи.

Під час запиту система не створює новий об'єкт через конструктор, а виконує клонування потрібного прототипу.

Етап 4. Реалізація клієнтського коду

Клієнт звертається до реєстру та отримує копію необхідного повідомлення.

Після клонування текст повідомлення може бути змінений незалежно від оригінального прототипу.
